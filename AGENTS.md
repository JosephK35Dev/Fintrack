# Reglas del proyecto
- No elimines funciones ni secciones existentes.
- No agregues dependencias. Stack: React, Tailwind v4, recharts, lucide-react.
- Los diseños de referencia están en /design. Deben replicarse con la mayor
  fidelidad posible: mismas medidas, colores, tipografías, animaciones y estados.
- Antes de terminar ejecuta `npm run build` y corrige los errores de TypeScript.
